# AI Judgment Toolkit

*A practical collection of prompts, protocols, checklists, and templates for preserving human judgment in AI-supported work.*

---

## Purpose

Artificial intelligence can generate increasingly polished outputs.

What it cannot do is assume responsibility for human judgment.

This repository contains practical tools that help individuals and organizations use AI while making human reasoning, evaluation, and decision-making more visible.

Rather than replacing human expertise, these resources are designed to strengthen it.

---

## What's Inside

This toolkit includes:

- Prompt libraries
- Decision-support protocols
- Evaluation frameworks
- Practical checklists
- Documentation templates
- Real-world examples

Everything is designed to be immediately usable.

---

## Guiding Principle

> AI may generate possibilities. Humans remain responsible for framing, evaluating, choosing, and acting.
